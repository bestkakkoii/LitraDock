# Native batch API

Implemented isolated candidate; public native cutover remains unqualified. Existing login/session/library/search contract remains. Every POST needs JSON, same-origin Origin, session cookie and X-CSRF. Errors are HTTP400/409/429/503 with bounded English messages. Account-generation and operation-generation fences must cover response headers, consumed JSON/blob and final UI/download side effects.

- `GET /service-info`: native schema advertises `batchLimit:10`, `searchEnabled`, `acquisitionEnabled` and existing source/operator/retention fields. Library catalog has `batches:[{batch_id,state}]` and totals.
- `POST /api/libraries/{library}/batches`: `{requestID:crypto.randomUUID(),searchIDs:[SearchId...]}`;1–10 unique saved records. Returns `{id}`. Reuse the same requestID only for retries of the same exact selection; another selection yields409. Cross-page selection must retain explicit record IDs and count.
- `GET /api/libraries/{library}/batches/{id}`: `{batch:{batch_id,state,created_at},items:[{search_id,rank,state,reason,attempts,original_hash,rights_uri,repository_stamp,source_uri,bytes,article,downloadAvailable,format,version}],total,counts,policy}`. Batch states active/paused/cancelled/complete/partial. Items queued/running/paused/cancelled/acquired/unavailable/unsupported/failed/transient/rate_wait. Show actual item reasons; acquired means server acquisition, not device Save.
- `POST /api/libraries/{library}/batches/{id}/control`: `{value:'pause'|'resume'|'cancel'|'retry'}`. Explicit retry only failed/transient/rate_wait items below3 attempts. Cancel preserves originals. Pause/resume keep selection and IDs.
- `GET /api/libraries/{library}/originals/{searchId}/{hash}`: XML attachment, gated by current server policy and byte/hash validation. Enable Save only when `downloadAvailable`; label exact per-original rights URI, XML format and repository-snapshot version disclaimer. No PDF or universal publisher login.
- `POST /api/libraries/{library}/exports`: `{runID,format:'csv'}` OR `{batchID,format:'csv'}`. CSV attachment, limit1000 saved rows /4MiB; no silent truncation. Export includes identifiers, direct links, batch reason/rights/hash. Blob generation fences must prevent download after observed invalidation/reauthentication.

All raw values render as text. Preserve DOI verbatim; optional `DoiLinkState:unsupported_path_segments` means a link cannot safely be supplied. Do not construct another normalized identifier. Source links remain available for unknown rights/unavailable items. The frontend supports guarded saved-batch reopen and bounded serialized progress refresh.

Native002 extension: `{batchID,format:'zip'}` on the same exports endpoint returns a consolidated ZIP with exact XML originals, `manifest.json` containing per-item state/reasons/rights/hash/source links, and `records.csv`. It rejects an aggregate original-byte budget above32MiB before assembly; no silently truncated bundle. Current-policy-denied or failed integrity items remain unresolved in the manifest. This does not establish XLSX export, PDF/media inclusion or broad capacity. Use the same after-body session-generation checks before triggering device download.

Batch catalog uses offset/limit100 with an independent batches total. Poll active batches serially, bound retries and discard after session/library/operation changes, including failures and401. Current availability may differ from historical acquired state after a policy downgrade; preserve the original but omit denied bytes from Save and ZIP.

# ADR0024 — one additional paired article-grant representation

Status: candidate; independent source-policy review and a separate genuine application PDF qualification are required before public activation.

The current cloud route rejects the captured PMC11852450.1 JATS at its rights-structure check. The listing identifies one deposit, version metadata agrees with PMID40001485 and DOI10.3390/biom15020182, and the JATS matches the advertised MD5. The article carries the complete MDPI whole-article CC BY4 paragraph recognized by ADR0022, with two differences: the license element has no `license-type` attribute, and the paragraph's visible license URL and link target use HTTPS. Offline replay against the predecessor reproduces rejection; the narrow paired representation change admits the captured grant. This is evidence about that capture, not proof that the PDF was downloaded.

Recognize exactly two paired representations: the existing lowercase `open-access` type plus HTTP paragraph link, and an attribute-free license element plus HTTPS paragraph link. XML namespace declarations remain allowed. Do not accept a cross-product of optional types and schemes, arbitrary prose, a bare ALI reference, or a metadata license code. Keep exact whole-article paragraph, copyright/year, ALI namespace/reference/scope, link namespace/target/text, complete text and all existing outside-grant conflict/scope checks. Identity, single-deposit selection, version/checksum binding, deposit eligibility, request pacing, size limits and original-byte preservation remain unchanged. Unreviewed representations stay held with direct source links.

JATS1.4 documents `license-type` as optional with no default; this explains why absence need not contradict the explicit article prose. It does not itself grant permission. [JATS attribute definition](https://jats.nlm.nih.gov/archiving/tag-library/1.4/attribute/license-type.html), [license element](https://jats.nlm.nih.gov/archiving/tag-library/1.4/element/license.html), checked September18,2026. PMC documents supported HTTPS cloud access and deposit version ordering; no new route or preferred-version inference is introduced. [PMC AWS documentation](https://pmc.ncbi.nlm.nih.gov/tools/pmcaws/).

Full captured article bytes remain private. The public synthetic test modifies the already attributed ADR0022 rights-only template; it contains no paper, real article metadata or product fallback. Opt-in tests pin actual private listing/metadata/JATS SHA256 values and verify advertised MD5, actual identities, and contradictory/data-only/foreign-identity counterexamples without network access. Additional synthetic tests cover unknown attributes/namespaces, mismatched link schemes, inherited/component scope, extra/contradictory grants and malformed XML. Old accepted captured rights remain a regression control.

No database, proof schema, API, dependency or resource-limit change. Existing schema8 remains required. A compatible-schema8 predecessor can read all data but will conservatively hold this new representation when revalidating originals; rollback must retain research and proof bytes and disclose temporary unavailability. Source-original PDF bytes must never be reconstructed or renamed from XML. Genuine acquisition and device export remain separate gates after independent review.

Independent review042 found an inherited rejection gap: explicit personal-use-only and may-not-be-shared notices outside the grant passed both profiles. The correction adds those two known prohibitions, including whitespace/case and mixed-inline text controls. This is a conservative finite notice guard, not complete interpretation of arbitrary legal language; unknown phrasing remains a limitation of this template policy. Both captured positive controls and prior scope/conflict counterexamples remain required.

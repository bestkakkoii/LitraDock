# ADR0012 — native selected batches and conservative article grants

Native design decision: bounded implementation and qualification do not establish a complete production release.

Use native Go net/http, pgx and PostgreSQL with a compiled React/TypeScript/Vite frontend. Schema1 is created by the native operator bootstrap only in an empty, explicitly named dedicated database. Provisioning creates an explicit account with the established standard-library PBKDF2 hasher and protected environment input; it never enables or overwrites an existing account. PostgreSQL account/session admission locks remain the security boundary. No .NET process, proxy or permanent compatibility service implements these native routes.

Store bounded original XML bytes in PostgreSQL bytea alongside immutable SHA256, separate PMID/PMCID/DOI, article association, source URI, rights URI, repository datestamp and policy version. This makes publication atomic with item completion and lets one PostgreSQL snapshot contain original bytes and metadata. It is a deliberate small-candidate tradeoff: eight MiB per original and256 MiB accepted originals, not a scalable blob-storage claim. Reuse validates the complete bytes and current policy. A native library never reads the pilot's object tree or database.

A batch admits1–10 explicit Search IDs with a UUID idempotency key. A repeated key requires the same sorted selection. Global admission locks bound queue/storage checks; a single worker lease serializes acquisition. Publication locks batch then item and checks active/running/current lease, so the tested cancellation-before-response ordering cannot publish late bytes. Expired leases resume unfinished items, and three interrupted attempts require operator review. Explicit retries honor persistent provider cooldowns. Pause and cancel preserve acquired originals. Current download/CSV/ZIP availability is revalidated separately from historical acquisition state.

Use only the official PMC OAI GetRecord endpoint and full-text pmc metadata format for this slice. Never follow redirects or use a publisher login, CAPTCHA workaround or PDF URL guess. Preserve the complete received OAI envelope; repository datestamp is not an asserted publication version. Unknown identity, numbered PMCID, structural ambiguity, mismatched IDs, missing article body, unknown rights, unsupported scope and denied access remain explicit unresolved states with source links. Source requests share persistent pacing of at least400ms, a lifetime250-request candidate budget and a100-request daytime allowance. These are local upper bounds, not permission to exceed an upstream restriction. [PMC OAI documentation](https://pmc.ncbi.nlm.nih.gov/tools/oai/) and [NCBI E-utilities guidance](https://www.ncbi.nlm.nih.gov/books/NBK25497/) are the primary mechanism/rate references used for this implementation.

A Creative Commons URI alone cannot resolve contradictory prose. Negative controls demonstrate that phrase lists can miss prohibited-use wording, and that a changed href can assign CC0 while article wording remains CC BY. The successor therefore requires one reviewed complete grant template, a neutral copyright-year scalar, reviewed JATS/ALI structure and attributes, and the matching CC BY4 URI. The canonical rights-text digest is5e7f2fde4289fe38b132577a63be1238ec050d4e7220eeb6475d65e7421e016e. A copyright-year or whitespace change may preserve that template; new wording, scope, namespace or grant URI requires another explicit policy revision. The small synthetic fixture contains licensed grant boilerplate and a synthetic year, not a paper or fabricated source result. A source's data-only CC0 statement is not promoted to the article license. [CC BY4 terms](https://creativecommons.org/licenses/by/4.0/) remain linked for attribution; this policy does not determine legal ownership or universal reuse rights.

This removes the permanent two-article assumption while intentionally admitting only one reviewed grant template. Additional templates and publication versions need pinned primary evidence, independent policy review and a coordinated real-source qualification. Known conflicting article grants are held independently of the template matcher. Broader real coverage needs its own qualification; fixture acceptance alone does not establish practical bulk completeness.

CSV exports preserve UTF-8 metadata and identifier/link strings with formula protection; they are not typed XLSX exports. ZIP contains exact admitted originals plus a consolidated manifest and CSV, with unresolved reasons/links and a32 MiB original-byte bound. Original acquisition is a server action; browser Save is a separate device action fenced by session, library and operation generations.

BaoTa remains the native application's sole supervisor. Root-owned PID/log/script parent paths and a UID check prevent an application-owned PID marker from targeting another account. A dedicated kernel cgroup limits the candidate; its resource setup unit does not supervise the application. Site-specific patches, credentials, host topology, rollback and operating receipts belong in protected operator storage, outside distributable source. Panel updates require requalification of the patched manager. Public cutover still requires its own deployment, corresponding-source, expiry/cleanup, migration and operational gates.

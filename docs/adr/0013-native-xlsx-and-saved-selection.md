# ADR-0013: Typed workbooks and selection of saved records

Status: implemented candidate; physical spreadsheet applications and wider source coverage remain unverified.

Use the native Go service to generate XLSX with locked Excelize v2.11.0. Its maintained Go implementation provides explicit string cells and external hyperlinks; it requires no office installation or additional server runtime. [Official Excelize documentation](https://xuri.me/excelize/en/) describes its BSD-3-Clause license and cell APIs. Actual runtime module licenses accompany the binary in THIRD_PARTY_NOTICES.md; go.mod/go.sum pin their versions and authenticated module content. This change does not establish vulnerability clearance or legal ownership.

Every exported cell uses an explicit string type and text number format, including Search ID, PMID, PMCID, DOI, year and byte count. Formula-like values remain literal text without adding an apostrophe or losing Unicode. HTTPS hyperlinks are separate relationships, restricted to the existing PubMed, PMC, DOI and Creative Commons hosts; unsafe values remain inert text. Identifier text, landing links, acquisition endpoint, original format/version/hash/bytes and repository datestamp occupy separate columns. Saved-run exports contain saved metadata; batch exports additionally contain current per-item state, reasons and original provenance. A batch may contain records from multiple runs, so its Search Run ID cell is empty and its Batch ID is explicit. CSV and original ZIP remain supported.

Reject an empty or over-1000-row export, unrepresentable XML text, cells above 32767 UTF-16 units, more than 4 MiB of cell text, or an output above 8 MiB. Return no truncated workbook. These export bounds do not widen the 100-record retrieval or 10-record batch admission limits. Export is read-only and uses existing account/session admission and library ownership checks; no schema migration or source-provider request is introduced.

Openpyxl 3.1.5 with defusedxml is a separately maintained acceptance reader, installed only for tests with hash-locked wheels. It checks exact text and hyperlink targets and rejects deliberate identifier, formula, numeric-cell, hyperlink and row mutations. It is not qualification in physical Excel, macOS or a mobile spreadsheet app. See [openpyxl documentation](https://openpyxl.readthedocs.io/en/stable/) and the [pinned release](https://pypi.org/project/openpyxl/3.1.5/).

Record page sizes are 5, 25, 50 and 100, default 25. Selection is a bounded map keyed by stable Search ID, retained across pages of the same saved run. A changed run, library, account or session invalidation clears selection; changed run/library/session invalidates pending export completion. Changing page size reloads saved records without creating a search; previous navigation uses the selected page size. Reopening saved runs and batches performs reads and never repeats acquisition. Provider total and retrieved/saved counts remain distinct, including isolated synthetic totals of 1000, 10000 and over 10000.

Rollback is a binary/static-asset rollback on the same unchanged database schema. Paired data backup and current operator procedures remain required before deployment. New workbooks already saved on a device remain ordinary files; their existence does not imply a server-side export job or full-text permission. Practical larger durable batches and broader permitted-source coverage are separate increments requiring budgets, resource measurements and rights review.
